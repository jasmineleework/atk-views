# atk-views
Shared client-side renderer for OKX Agent Trade Kit inline views (analysis + conclusion). Loaded from jsDelivr; the chat streams only a small data object.

```html
<div id="v"></div>
<script src="https://cdn.jsdelivr.net/gh/jasmineleework/atk-views@ddcac15/atk-views.js"></script>
<script>ATK.analysis(document.getElementById('v'), {...});</script>
```
